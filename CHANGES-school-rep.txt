HOW A DECISION WORKS: approving runs the same step an administrator's approval runs (verified_coach role, joins the
school, coach notified, audit entry). Rejecting needs a reason (1 to 500 characters) which the coach is shown.
Only PENDING requests of the rep's own school can be decided; one transaction with a row lock, so it can't collide
with an administrator deciding the same request.
